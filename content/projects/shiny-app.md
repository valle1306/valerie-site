# Interactive R/Shiny app for multiple testing

An interactive Shiny app developed with faculty collaboration to visualize hypothesis graphs and redistribute test weights dynamically for multiple testing procedures. Features JSON import/export, node/edge editing, and dynamic visual updates.

Details:

- Built with R/Shiny and integrated into reproducible unit tests
- Deployed internally and used as a demo for TrialSimulator
- Designed for accessibility to applied biomedical researchers
