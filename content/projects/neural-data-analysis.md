# Neural data analysis toolkit

Short description: Reproducible pipelines for preprocessing and analyzing electrophysiology and calcium imaging data. Includes automated QC, spike-sorting wrappers, and visualization modules.

Technologies: Python, numpy, pandas, matplotlib, seaborn, MNE, custom wrappers.
