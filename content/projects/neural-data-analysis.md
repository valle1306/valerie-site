# Neural data analysis toolkit

Pipelines and reproducible analyses for spike and imaging datasets. Includes preprocessing, quality control, and example analysis notebooks to reproduce published figures and exploratory analyses.

Key features:

- Reusable preprocessing pipelines (spike sorting wrappers, imaging preprocessing)
- Example notebooks demonstrating population analyses and visualization
- CI-friendly tests and Dockerized workflows for reproducibility
