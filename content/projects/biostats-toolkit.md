# Biostatistics toolkit

An opinionated set of R and Python utilities for model fitting, reporting, and reproducible analysis pipelines. Includes helpers for hierarchical/Bayesian modeling, plotting standards, and reproducible reporting templates.

Highlights:

- Reusable model wrappers and diagnostics
- Templates for reproducible reports (R Markdown / Jupyter)
- Unit tests and example analyses
